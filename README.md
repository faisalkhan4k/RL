# CircuitWise — SalesRLAgent

A voice-guided electronics storefront with real product snapshots, Deepgram STT/TTS, Groq, LangGraph, OpenTelemetry, and a read-only demo MCP inventory/order server.

All application files are under [apps/salesrlagent](apps/salesrlagent). See the [setup guide](apps/salesrlagent/README.md) and [commerce documentation](apps/salesrlagent/docs/COMMERCE.md).

Cart, stock, orders and checkout are demos. No real merchant account is connected. Research policies train on synthetic customers; no real-world sales performance claim.
